# Project Workflow

## 1. Development Protocol
- **Tests:** No automated tests are required for this project.
- **Commits:** Conductor will not enforce git commits. You are responsible for manually saving or committing your work if desired.
- **Task Tracking:** Task progress will be tracked by updating the status in the `plan.md` file.

## 2. Task Completion Definition
A task is considered complete when:
1. The requested changes have been implemented.
2. The implementation has been manually verified by the user.

## 3. Phase Completion
- At the end of each phase, review the completed tasks to ensure the goal of the phase has been met.
