# Technology Stack

## Core Components
- **Application:** Waybar (Status bar for Wayland)
- **Configuration Format:** JSONC (JSON with comments)
- **Styling Engine:** CSS (GTK3 CSS subset)

## Scripting & Automation
- **Language:** Bash (Shell scripting for custom modules)

## Dependencies & Integrations
- **Compositor:** Niri (Scrollable Tiling Wayland Compositor)
- **Launcher/Menus:** Rofi (Application launcher, power menu, network menu)
- **Notifications:** SwayNC (Sway Notification Center)
- **Media Control:** Playerctl (MPRIS command-line controller)
- **Brightness Control:** `brightnessctl` (local display) and `ddcutil` (external monitors)
- **Bluetooth:** Blueman (via `blueman-manager`)
- **Network:** NetworkManager (via `nm-connection-editor`)
- **Audio:** PulseAudio/PipeWire (via `pavucontrol`)

## Assets
- **Fonts:** Nerd Fonts (Iosevka Nerd Font, JetBrainsMono Nerd Font)
