# Product Guide: Niri-Waybar-Gruvbox

## Initial Concept
A customized Waybar configuration tailored for the Niri Wayland compositor, featuring a Gruvbox Material Hard Dark theme and integrated system controls.

## Target Audience
- **Niri Compositor Users:** Individuals using the Niri Wayland compositor who need a compatible and aesthetically matching status bar.
- **Linux Enthusiasts:** Users who appreciate the Gruvbox Material Dark aesthetic and want a high-contrast, distraction-free interface.
- **Power Users:** Individuals who require detailed system statistics (CPU, RAM, Disk) and efficient, keyboard-centric workflows integrated into their desktop environment.

## Core Value Proposition
This project delivers a polished, functional, and visually cohesive status bar experience for Niri. It bridges the gap between raw functionality and aesthetic consistency by providing a pre-configured, theme-aware setup that works out of the box with essential system utilities.

## Key Features
- **Niri Integration:** Native support for Niri workspaces and window titling.
- **Gruvbox Aesthetic:** A comprehensive `style.css` implementing the Gruvbox Material Hard Dark theme for a consistent look.
- **System Monitoring:** Real-time modules for CPU, Memory, Disk usage, and Battery status.
- **Control Modules:** Integrated controls for Network, Bluetooth, PulseAudio, Media (MPRIS), and Brightness.
- **Custom Scripting:** Rofi-based menus for Power management, Network selection, and Brightness presets.
